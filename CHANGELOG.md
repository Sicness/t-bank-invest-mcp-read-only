# История изменений

Версии следуют [семантическому версионированию](https://semver.org/lang/ru/) применительно к контракту инструментов: названия инструментов и параметров не меняются и не удаляются, а с версии 1.0.0 из ответов не убираются поля. Раздел версии из этого файла становится описанием её релиза на GitHub.

## 1.0.0

Первый выпуск на PyPI. Установка — `uvx t-bank-invest-mcp-read-only`, подробнее в README. Сервер также есть в реестре MCP-серверов: `io.github.Sicness/t-bank-invest-mcp-read-only`.

### Если вы запускали сервер с `main` до этого выпуска

Названия инструментов и их параметры не изменились: настройки клиентов, списки разрешений и промпты продолжают работать. Изменился формат ответов — это заметят только скрипты, которые разбирают ответы сами.

- **Суммы и цены — числа.** Вместо `{"units": "274", "nano": 270000000}` — `274.27`. Валюта указана один раз, в поле `currency` того же объекта; сумма в другой валюте записана как `{"value": ..., "currency": ...}`.
- **В длинных списках опущены пустые поля.** Позиции, операции и события облигаций не содержат полей, равных нулю, `false` или пустых. Отсутствие поля означает ноль или «нет».
- **В операциях убраны поля-повторы:** `instrumentKind` (есть `instrumentType`), `assetUid`, `brokerAccountId` и `cursor` у каждой операции (есть `nextCursor`). В портфеле — устаревшие `averagePositionPricePt` и `quantityLots`.
- **`get_candles` возвращает строки:** `{"columns": ["time", "open", "high", "low", "close", "volume", "volumeBuy", "volumeSell"], "candles": [[...], ...]}`. У дневных и более длинных свечей время — дата.
- **`find_instrument` возвращает короткие записи** (`{"instruments": [...], "total": N}`). По умолчанию в них только бумаги, торгуемые через API, и не больше 20.
- **`get_operations_by_cursor` по умолчанию отдаёт 50 операций, а не 100.** Сотня операций больше, чем клиент пропускает в контекст.
- **Ответы — компактный JSON** без отступов, и каждый ответ отправляется клиенту один раз, а не дважды.

Зачем это сделано: ответы читает модель, и раньше портфель на сотню позиций не помещался в её контекст — клиент отклонял каждый вызов `get_portfolio`. Теперь портфель на 106 позиций занимает около 40 тыс. символов, страница операций — около 28 тыс.

### Добавлено

- **Инструмент можно назвать как угодно** — тикером, FIGI, ISIN или UID — в любом параметре, который принимает инструмент. Если под одним тикером торгуются разные бумаги (`T` — это и Т-Технологии, и AT&T), сервер перечислит варианты и попросит уточнить в виде `T_TQBR`.
- **`get_stock_snapshot`** — сводка по акции одним вызовом: фундаментальные показатели, изменение цены за несколько сессий и консенсус-прогноз.
- **`find_instrument`** получил фильтр по типу инструмента (`instrument_kind`), параметр `tradable_only` и ограничение числа результатов.
- **Допустимые значения перечислений видны в схеме инструментов** (интервалы свечей, типы индикаторов, статусы операций), а префикс вроде `CANDLE_INTERVAL_` можно не писать.
- **Инструменты помечены как только читающие** (`readOnlyHint`), так что клиент может не спрашивать подтверждение на каждый вызов.
- **Описания инструментов говорят, как читать ответ:** отменённые заявки тоже приходят в операциях и несут сумму заявки; `quantity` — заявлено, `quantityDone` — исполнено; `expectedYield` позиции — сумма, а не проценты; свечи пересчитаны на сплиты, операции — нет.

### Исправлено

- **Диапазоны дат:** `to_date` включает указанный день целиком; раньше последний день периода выпадал.
- **Фильтры, которые API молча игнорировал.** Тип события облигации (`CPN`, `CALL`, `MTY`, `CONV`), статус операции и валюта портфеля теперь проверяются: неизвестное значение — ошибка, а не ответ без фильтра.
- **`get_consensus_forecasts`** находит прогноз по инструменту: раньше он искал по идентификатору инструмента там, где API использует идентификатор актива.
- **`get_tech_analysis`** работает: у этого метода свои названия интервалов, а для полос Боллинджера и MACD API требует параметры, которые сервер не передавал.
- **Ошибки объясняют причину.** В тексте ошибки — ответ API и его код, для таймаутов и сетевых сбоев — понятное описание. Токен в текст ошибки не попадает.
- **Сертификат.** Сервер работает с `invest-public-api.tbank.ru` и доверяет корневому сертификату Минцифры только для этого соединения, не требуя ставить его в систему.

### Известные ограничения

- `list_shares`, `list_bonds`, `list_etfs` и `list_futures` отдают полные справочники — от 300 КБ до 2,4 МБ. В контекст модели они не помещаются; для поиска бумаг используйте `find_instrument`.
- `get_operations` не разбит на страницы: держите период в пределах месяца-двух или используйте `get_operations_by_cursor`.
